Why it's nice

Everything you'd want from a desktop app

It behaves like a first-class Mac citizen — not a browser tab pretending to be one.

Always signed in

Persistent cookies and local storage keep your session intact across every launch.

Native menu bar

Reload, history, full screen, and the standard editing shortcuts — all where you expect them.

Uploads & downloads

File uploads run through the native open panel; downloads land straight in ~/Downloads.

Smart link handling

Vibe and its sign-in providers stay in-app; every other link opens in your default browser.

Get started

Up and running in a minute

Download the disk image, drag to Applications, approve it once.

Download

Grab the latest Vibe.dmg from the Releases page.

Drag to install

Open the .dmg and drag Vibe into your Applications folder.

Approve once

First launch: open System Settings → Privacy & Security and click Open Anyway. macOS remembers it.

The app is signed ad-hoc rather than with an Apple Developer ID, so the first launch needs Gatekeeper's approval — you only do this once. Prefer the Terminal? Clear the quarantine flag instead: xattr -dr com.apple.quarantine /Applications/Vibe.app
For developers

Build it yourself in two commands

One Swift source file, no package manager, no node_modules. All you need is the Swift toolchain from Xcode or the Command Line Tools.

  • Universal binary by default — set ARCHS to target one arch.
  • A single styled drag-to-install .dmg packaging script.
  • App icon generated from inline SVG — no design tools required.
zsh — vibe
# clone & build the app bundle
$ git clone https://github.com/Alyetama/mistral-vibe-desktop
$ cd mistral-vibe-desktop
$ ./scripts/build.sh
  → build/Vibe.app

# run it
$ open build/Vibe.app

# or package the styled installer
$ ./scripts/make-dmg.sh
  → dist/Vibe-1.0.0.dmg
